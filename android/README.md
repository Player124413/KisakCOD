# KisakCOD — Android Port

Портирование [KisakCOD](https://github.com/SwagSoftware/KisakCOD) (реализации
Call of Duty 4 с открытым исходным кодом) на Android: лаунчер, автоматический
перенос файлов игры, сенсорное управление с полноценным режимом **EDIT** и
рендер на OpenGL ES.

> 🇬🇧 The port of the open-source [KisakCOD](https://github.com/SwagSoftware/KisakCOD)
> COD4 reimplementation to Android: launcher, automatic game-file placement,
> touch controls with a full **EDIT** mode and an OpenGL ES renderer.

приложение запускается без движка и показывает демо-сцену поверх оверлея.

## Сборка

Нужен **Android Studio** (или SDK + NDK + JDK 17):

```
Android SDK Platform 34
Android NDK r26d (26.3.11579264)
CMake 3.22.1 (из SDK)
```

1. Откройте папку `android/` в Android Studio.
2. Дайте Gradle скачать AGP 8.3.2 и Kotlin 1.9.23 (первая сборка — один раз).
3. Зависимостей на стороне приложения **нет** — Kotlin-код использует только
   платформенные API (`android.*`), так что сборка работает офлайн.
4. `Build > Build APK(s)` (релиз/дебаг).

Из командной строки:

```bash
cd android
./gradlew :app:assembleDebug          # или:
./gradlew :app:installDebug           # при подключённом устройстве
```

Итоговый APK: `android/app/build/outputs/apk/debug/app-debug.apk`.

### Нативные тесты (можно гонять на любом Linux-хосте, без NDK)

```bash
bash android/tests/build_and_run.sh
```

Проверяет: маппинг кнопок на клавиши движка, зоны мёртвости джойстиков,
диагонали, чувствительность/инверсию Y, выключение сенсорного управления,
декодирование DXT1/DXT5 (реальные DDS текстуры игры), таймеры, потоки, шимы
`VirtualAlloc`. Все проверки сейчас зелёные.

## Установка и использование

1. Установите APK, откройте лаунчер.
2. **Перенос файлов игры** — любой из трёх способов:
   - «Импортировать папку с игрой» → укажите папку, где лежат `main/`, `zone/`
     (например `Call of Duty 4/`). Приложение само найдет их на любой глубине и
     разложит в нужное место;
   - «Импортировать ZIP» → выберите архив;
   - или «Открыть через» ZIP → он сам запустит импорт.
3. Проверьте профиль производительности (Авто/Слабый/Средний/Мощный/Флагман)
   и «Применить» — будет записан `android_launcher.cfg`.
4. «Запустить игру».

> Файлы игры не модифицируются и не ломаются: импорт только копирует.
> Место данных: `Android/data/com.kisakcod.android/files/`.

### Редактор раскладки (EDIT)

В игре нажмите **EDIT** (круглая кнопка вверху по центру):

- тап по кнопке — выбрать;
- перетаскивание — **переместить**;
- угловой маркер — **изменить размер**;
- «Скрыть/Показать» — **видимость** кнопки;
- «Действие» — сменить действие кнопки (огонь, прыжок, …);
- «Сенсор: ВКЛ/ВЫКЛ» — **выключить/включить всё сенсорное управление**
  (удобно, когда подключён геймпад);
- «Сетка» — привязка к сетке; «Размер ±» — точная подгонка; «Сброс» — дефолты;
- «Готово» — сохранить.

Раскладка сохраняется между запусками (простой текст, легко шарить и править
руками).

### Поддерживаемые устройства

- minSdk **24** (Android 7.0+) — ~99% активных устройств;
- ABI: arm64-v8a, armeabi-v7a (старые 32-битные), x86_64 (эмуляторы);
- слабые устройства: профиль «Слабый» (30 FPS, picmip 2, без теней/воды).

## Дорожная карта

- **M1 (готово):** лаунчер, импорт, профили, оверлей + EDIT, JNI/EGL-хост,
  shell-режим, тесты.
- **M2 (начато):** платформенный слой движка — события, потоки, память,
  файловая система (`src/_platform/android/*`, `and_main.cpp`); первый
  компилируемый `KisakCOD-dedi` под Android + OpenAL-звук.
- **M3 (начато):** `gfx_gles` — перевод фронтенда/бэкенда рендера с D3D9 на
  GLES3 (пути меню/HUD первыми; `r_image_dds` уже готов и протестирован).
- **M4:** оптимизации (динамическое разрешение, предзагрузка, JIT-профили),
  многопоточный рендер под слабые SoC.

Подробности: **`../ENGINE_PORT.md`**.
